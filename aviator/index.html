Provably Fair र क्रिप्टोग्राफिक RNG

एभिएटरको सबैभन्दा महत्त्वपूर्ण प्राविधिक पाटो — Provably Fair system। हरेक राउन्डको परिणाम तीन घटकको cryptographic mix द्वारा निर्धारण हुन्छ:

  1. Server seed: Spribe ले राउन्ड सुरु अघि sealed (hash) रूपमा प्रकाशित गर्छ।
  2. Client seed: तपाईंको browser/app ले randomly generate गर्छ।
  3. Nonce: राउन्ड क्रम संख्या।

यी तीनको SHA-256 hash ले उक्त राउन्डको crash multiplier तय गर्छ। राउन्ड सकिएपछि Spribe ले unsealed server seed प्रकाशित गर्छ, र तपाईं आफै hash verify गर्न सक्नुहुन्छ। यदि result ले hash सँग नमिले, खेल rigged हो — तर यो आजसम्म कहिल्यै देखिएको छैन।
